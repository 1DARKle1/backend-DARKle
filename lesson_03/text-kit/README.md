# Text Kit

Набор из шестнадцати небольших функций: строки, даты, расчёты по числам
и проверка введённых данных. Программа печатает пример работы каждой функции.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## По какому признаку функции разделены

Функции разложены по теме, а не по порядку в старом `main.py`. Строки и даты
пригодятся в любом проекте, поэтому они лежат в `app/utils/`. Расчёты по числам
и проверка введённых данных - правила этого проекта, они лежат в `app/services/`.
`app/main.py` только хранит примеры данных и печатает их.

`validation.py` вызывает `clean_spaces` из `utils/text.py`. Это единственная
связь между модулями, кроме точки запуска. `services` и `utils` не импортируют `main`.

## Структура

```text
text-kit/
├── README.md                   назначение, запуск, результат
├── app/
│   ├── __init__.py             пакет приложения
│   ├── main.py                 точка запуска: данные примера и печать
│   ├── services/               правила этого проекта
│   │   ├── __init__.py
│   │   ├── statistics.py       среднее, медиана, разброс, подсчёт значений
│   │   └── validation.py       почта, телефон, пароль
│   └── utils/                  функции, пригодные в любом проекте
│       ├── __init__.py
│       ├── dates.py            чтение, запись и сравнение дат
│       └── text.py             пробелы, обрезка, инициалы, адрес страницы
└── tests/
    ├── test_dates.py
    ├── test_statistics.py
    ├── test_text.py
    └── test_validation.py
```

## Запуск

Команды выполняются из корня проекта.

```text
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`.
